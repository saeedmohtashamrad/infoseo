# ساختار سایت

## نقشهٔ آدرس‌ها

| آدرس | محتوا |
|---|---|
| `/` | صفحهٔ اصلی (قابل‌تعویض از پنل) |
| `/services/` | فهرست همهٔ ابزارها با جستجو و دسته‌بندی |
| `/services/{نام-ابزار}` | صفحهٔ هر ابزار (یک آدرس پایدار برای هر ابزار) |
| `/blog`، `/blog/{slug}`، `/blog/category/…`، `/blog/tag/…`، `/blog/feed` | بلاگ (RSS، جستجو، آدرس فارسی) |
| `/seo-analyzer` | آنالیزور حرفه‌ای (رایگان با PageSpeed + حالت پولی هوش مصنوعی) |
| `/rank-tracker` | ردیاب رتبه (برای اعضای دعوت‌شده) |
| `/login`، `/account` | ورود پیامکی و حساب کاربری (noindex) |
| `/about-us`، `/contact-us` | صفحه‌های ثابت |
| `/sitemap.xml`، `/robots.txt` | ساخته‌شده خودکار |
| `/api/v1/{slug}` | API ابزارهای سمت‌سرور (POST، فقط درخواست هم‌مبدأ، با محدودیت نرخ) |
| `/api/bot/{tg\|bale}/{کلید}` | webhook ربات تلگرام و بله (آدرس مخفی) |
| `/account/bot` | اتصال حساب سایت به ربات |
| `/admin/…` | پنل مدیریت |

## ساختار کد (مخزن خصوصی)

```
index.php                 front controller
app/
  Core/                   روتر، تنظیمات، دیتابیس، کش، نشست، SEO، ماژول‌ها، TOTP
  Controllers/            سایت، API، بلاگ، حساب، ادمین، ردیاب رتبه
  Tools/                  رجیستری ابزارها، ورودی/خروجی استاندارد (F, R, Input)
  Tools/defs/*.php        تعریف ۶۹ ابزار (داده، نه صفحه)
  Security/               کلاینت امن HTTP (ضد SSRF)، بررسی آدرس
  Cms/ Blog/ Account/     CMS، بلاگ، حساب و اعتبار
  Rank/                   ردیاب رتبه و پایش محتوای رقبا
  Bot/                    ربات تلگرام و بله (فهرست ابزارها از همان رجیستری سایت)
  Views/                  قالب‌ها (هدر و فوتر فقط در یک جا)
assets/
  css/ js/ js/tools/      استایل، جاوااسکریپت و ابزارهای مرورگری
cron/                     کار زمان‌بندی‌شده (فقط CLI)
```

## تصمیم‌های مهم

1. **یک منبع برای هدر و فوتر**: همهٔ صفحه‌ها از یک پارشیال استفاده می‌کنند و منوها از تنظیمات می‌آیند.
2. **تعریف ابزار = داده**: افزودن یک ابزار یعنی افزودن یک فایل. صفحه، متای SEO، FAQ، لینک‌های مرتبط و نقشهٔ سایت خودکار ساخته می‌شوند.
3. **ماژول‌های قابل‌خاموش**: بلاگ، حساب کاربری، آنالیزور، ردیاب رتبه و … جدا روشن/خاموش می‌شوند؛ ماژول خاموش ۴۰۴ می‌دهد و داده‌ای پاک نمی‌شود.
4. **کش صفحهٔ کامل** برای صفحه‌های عمومی و وضعیت ورود با یک کوکی راهنما (کش خراب نمی‌شود).
5. **ابزار مرورگری تا جای ممکن**: وقتی کار لازم نیست به سرور برود، به سرور نمی‌رود.
